COMS BC3930: Module 2 Documentation

Interactive Devices

For Module 2, the goal was to create an interactive device using the ESP32 TTGO T-display, a joystick, a push button, and a potentiometer. By sending sensor data via serial communication to a laptop, the program generates a dynamic media interface to create something both interesting and practical.

My initial dilemma was how to explore my prior knowledge on electrical circuits without getting bogged down in lower levels of abstraction. Furthermore, I wanted to create something genuinely helpful. Inspired by the convenience of a counter clicker, I decided on a physical task and habit tracker to eliminate the friction of updating analog planners when they aren't nearby.

The device leverages a rich sensory experience: users press the button to toggle task status (completed/uncompleted), use the joystick horizontally to switch design themes, and turn the potentiometer to scroll through active tasks. Peer feedback during the showcase highlighted how much satisfying tactile encouragement physical controls add compared to purely digital interactions.

Circuit Construction

The electrical circuit was constructed on a breadboard by connecting the sensors to specific analog and digital pins on the ESP32:

  • Pushbutton: Connected to pin 15
  • Potentiometer: Connected to pin 13
  • Joystick (VRX): Connected to pin 39
  • Joystick (VRY): Connected to pin 32
  • Joystick (SW): Connected to pin 33 (initially wired during design, though ultimately unused)
  • Joystick (GND & +5V): GND to GND, +5V to +3V power rail (to normalize potentiometer readings)

Code Implementation & Challenges

Building on Lab 2 code, I transitioned input controls from the ESP32's built-in buttons to the external pushbutton and handled state toggling directly through Arduino rather than dual buttons. To prevent overwhelming the system, serial prints were optimized to trigger only upon state changes.

A major challenge arose when integrating the potentiometer data with the button states over a single serial communication stream. Initially, the potentiometer values for active task selection conflicted with the button toggle messages. To resolve this, the potentiometer reading was mapped to a currentTask variable:

int potValue = analogRead(POT_PIN);
                int currentTask = (potValue * NUM_TASKS) / 4096;
                if (currentTask >= NUM_TASKS) {
                    currentTask = NUM_TASKS - 1;
                }

This variable is packed alongside button events, active themes, and joystick actions into a single serial string sent to Processing, where the active task is highlighted visually and updated dynamically.

Joystick Interactions: Themes & Reset Safety

The joystick serves a dual purpose:

  • X-Axis (Theme Selection): Allows users to cycle through different UI themes, balancing personal aesthetic preferences (such as minimalist function-over-form layouts vs. more elaborate visuals).
  • Y-Axis (Hold-to-Reset): Implements a 0.5-second hold requirement (resetHoldTime) to prevent accidental task resets.

Future Ideas & Peer Feedback

Peer suggestions included adding a direct text-input box and integrating an API to maintain tracker history. Personal future ideas include adding a Tamagotchi-like virtual pet that evolves alongside your productivity progress to further motivate task completion.
